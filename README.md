# 🎴 LevelUP Designers — Product Design Mastery Deck

An interactive daily learning, practice, and skill-building web application designed for UX/UI and Product Designers of all levels.

![LevelUP Designers](logo.png)

---

## ✨ Features

- 🃏 **Interactive Physical Paper Deck**:
  - Tactile stacked paper cards with realistic corner tears, peeling animations, and audio haptics.
  - Multi-tier curriculum across **Beginner**, **Intermediate**, and **Advanced** mastery levels.
  - Multi-discipline study domains (Product Design, Design Systems, UX Research, Interaction Design, Product Strategy, Growth Design).

- 🤖 **Smart Multi-Provider AI Topic Generator**:
  - Auto-detects and connects with **Google Gemini (Free Tier)**, **OpenAI (GPT-4o)**, **Anthropic Claude**, **Groq (Llama 3.3)**, and **OpenRouter**.
  - Generates custom, non-repeating topics tailored dynamically to your level and field of study.

- 📚 **Comprehensive 360° Resources Library**:
  - **Articles**: In-depth research & frameworks from Nielsen Norman Group (NN/g), UX Collective, Interaction Design Foundation (IxDF), Smashing Magazine, and HBR.
  - **Videos**: Masterclasses, live Figma workflows, case study teardowns, and heuristic breakdowns.
  - **Websites & Tools**: Direct links to Mobbin UI flows, Laws of UX, Component Gallery, Built For Mars, and Pageflows.

- ⏱️ **Multitasking Picture-in-Picture Companion**:
  - Automatically launches a floating companion window when switching tabs or minimizing.
  - Features a large live ticking focus timer and one-click expand to return to the main deck.

- 🎨 **Comic & Y2K Designer Stickers**:
  - Interactive background stickers with gentle leaf-drifting physics.
  - Pure bold graphite typography with high-contrast pop shapes.

- 📖 **Reading Journal & Trash Bin**:
  - Save completed topics with dates and times.
  - Built-in search, filtering, and 30-day auto-purge recycle bin.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/msaisantoshAI/LevelUp-Designer.git
cd LevelUp-Designer
```

### 2. Install dependencies & run
```bash
npm install
node serve.js
```

### 3. Open in Browser
Visit **[http://localhost:8080](http://localhost:8080)** in your browser.
